# Баннер горячей линии санатория «Белокуриха»

[Открыть демку](https://kirschmunk.github.io/Kurort-Food/belokurikha-hotline/)

Вариант «Светлая полоска», версия 3: сбалансированная композиция с увеличенной типографикой и вертикальными отступами 34 px на широком экране. Текст с иконкой сдвинуты левее, телефон — правее; боковые поля сопоставимы с визуальным расстоянием от текста до кнопки. Готовый адаптивный HTML/CSS-блок без JavaScript, внешних библиотек и запросов к сторонним сервисам. Кнопка звонка: **8 800 707 51 83** (`tel:+78007075183`).

## Установка

1. Скопировать папку `belokurikha-hotline` на сайт, например в `/assets/belokurikha-hotline/`. Сохранить вложенную папку `assets/fonts`: оба шрифта входят в комплект, CSS использует относительные пути к ним.
2. Подключить CSS **после основных стилей сайта**:

```html
<link rel="stylesheet" href="/assets/belokurikha-hotline/hotline.css?v=3">
```

3. В нужном месте главной страницы **внутри существующей колонки** `.e1-container` (или `.wrapper`) вставить всё содержимое [block.html](./block.html). Блок имеет ширину 100% родительской колонки. Не добавлять ещё один контейнер внутри уже имеющегося.

Пример для PHP, если блок нужно вывести отдельной строкой вне существующего контейнера:

```php
<div class="e1-container" style="margin-top: 24px; margin-bottom: 24px;">
  <?php include $_SERVER['DOCUMENT_ROOT'] . '/assets/belokurikha-hotline/block.html'; ?>
</div>
```

Можно просто скопировать HTML из `block.html` в шаблон вместо `include`.

## Размер и адаптивность

Размеры сверены с опубликованными стилями главной страницы `www.belokurikha-san.ru` 6 ноября 2026 года:

- `.e1-container`: максимум 1260 px с боковыми отступами по 30 px; **ширина содержимого — 1200 px**.
- До 991 px: контейнер 90% ширины окна, отступы по 20 px.
- До 767 px: контейнер 95% ширины окна, отступы по 15 px.
- Демка повторяет эти размеры. Сам баннер не задаёт колонке новую ширину и также помещается в старую `.wrapper` сайта.
- На широком экране текстовая колонка ограничена 600 px; между колонками — 24 px, сверху и снизу — по 34 px. Группа центрирована: при ширине баннера 1200 px боковые поля составляют примерно 130 px, а визуальный промежуток между строкой описания и кнопкой — примерно 140 px. На более узком экране эти расстояния уменьшаются.
- При доступной ширине баннера до 760 px телефон переносится под текст, кнопка растягивается на ширину блока. Предусмотрен запасной мобильный стиль для старых браузеров без container queries.

## Что входит

- `block.html` — готовый фрагмент для вставки.
- `hotline.css` — изолированные стили с префиксом `bk-hotline-`.
- `assets/fonts/Acrom-Regular.woff`, `Acrom-Bold.woff` — шрифты.
- `index.html` — только демка; её обёртку и стили `.demo-column` переносить на сайт не нужно.

Иконки уже встроены в HTML как SVG. Сборка, JavaScript и дополнительная настройка не нужны. Баннер не открывает попап и не собирает данные; ссылка предлагает звонок штатными средствами устройства. На компьютере результат зависит от наличия приложения для звонков.

После установки проверить, что CSS и оба шрифта загружаются без ошибок, телефон соответствует `+78007075183`, блок выровнен по соседним секциям и нет горизонтальной прокрутки на телефоне. Если на сайте включён кеш, сбросить его после публикации.
