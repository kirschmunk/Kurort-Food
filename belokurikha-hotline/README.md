## Установка

1. Скопировать папку `belokurikha-hotline` на сайт, например в `/assets/belokurikha-hotline/`. Сохранить вложенную папку `assets/fonts`: CSS использует относительные пути к обоим шрифтам. Иконка MAX уже встроена в CSS.
2. Подключить CSS **после основных стилей сайта**:

```html
<link rel="stylesheet" href="/assets/belokurikha-hotline/hotline.css?v=6">
```

3. В нужном месте главной страницы **внутри существующей колонки** `.e1-container` (или `.wrapper`) вставить всё содержимое [block.html](./block.html). Блок имеет ширину 100% родительской колонки. Не добавлять ещё один контейнер внутри уже имеющегося.

Пример для PHP, если блок нужно вывести отдельной строкой вне существующего контейнера:

```php
<div class="e1-container" style="margin-top: 24px; margin-bottom: 24px;">
  <?php include $_SERVER['DOCUMENT_ROOT'] . '/assets/belokurikha-hotline/block.html'; ?>
</div>
```

Можно просто скопировать HTML из `block.html` в шаблон вместо `include`.

При обновлении неизменённой версии 4 или 5 заменить `hotline.css`, изменить параметр версии CSS на `v=6`. HTML-фрагмент не изменился. Если CSS уже адаптирован разработчиком, используйте маленькое исправление по ссылке выше вместо полной замены. При обновлении версии ранее 4 также заменить HTML-фрагмент.

- До 767 px: контейнер 95% ширины окна, отступы по 15 px.

- На широком экране текстовая колонка ограничена 500 px; между основными колонками — 24 px, сверху и снизу — по 34 px. Телефон и MAX стоят рядом, высота обеих кнопок — 54 px. Подпись «Бесплатно по России» относится только к телефону.
- При доступной ширине баннера до 1000 px контактная группа переносится под текст; до 760 px занимает всю ширину блока, до 500 px кнопки располагаются одна под другой. Предусмотрен запасной мобильный стиль для старых браузеров без container queries.

## Что входит

- `block.html` — готовый фрагмент для вставки.
- `hotline.css` — изолированные стили с префиксом `bk-hotline-`.
- `assets/fonts/Acrom-Regular.woff`, `Acrom-Bold.woff` — шрифты.
- `assets/max-logo.svg` — оптимизированный векторный значок MAX на основе официального контура.
- `index.html` — только демка; её обёртку и стили `.demo-column` переносить на сайт не нужно.

Иконки гарнитуры и телефона встроены в HTML как SVG, логотип MAX — в CSS как SVG data URL. Файл `assets/max-logo.svg` оставлен как редактируемый исходник, при загрузке страницы он не запрашивается. Сборка, JavaScript и дополнительная настройка не нужны. Баннер не открывает попап и не собирает данные; телефонная ссылка предлагает звонок штатными средствами устройства. На компьютере результат зависит от наличия приложения для звонков. MAX открывает указанную выше официальную ссылку в новой вкладке; дальнейшее открытие чата зависит от приложения и авторизации пользователя. Тестовые сообщения не отправлялись.
