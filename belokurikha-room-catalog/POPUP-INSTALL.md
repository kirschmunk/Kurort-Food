# Поп-ап для уже установленной страницы номеров

Старые поп-апы и jQuery не нужны. Форма сама открывается по всем кнопкам `data-book-room`, показывает выбранный номер, проверяет имя, телефон и согласие. Фотографии и описания продолжают работать отдельно.

## 1. Скопировать два файла

Поместить рядом с `catalog.js` на сайте:

- [booking-popup.js](booking-popup.js)
- [booking-popup.css](booking-popup.css)

Для текущей страницы это папка `/nomera-temp/`.

## 2. Добавить одну строку перед `</body>`

```html
<script src="/nomera-temp/booking-popup.js?v=20261103-popup1" defer data-booking-mode="live"></script>
```

CSS и HTML формы подключатся автоматически. В самом `catalog.js` ничего менять не нужно. Не подключайте параллельно другой обработчик бронирования. Вложенные `<a class="js-theme-modal">` внутри кнопок можно удалить, оставив текст «Забронировать»: модуль работает и с текущей разметкой, но чистая кнопка корректнее.

В готовом `block.html` эта строка уже есть для папки `/upload/belokurikha-room-catalog/`. Повторно не добавлять. После обновления очистить кэш.

## 3. Отправка заявки

Открытие формы полностью готово. Отправка использует существующий адрес сайта:

```text
POST /includes/theme-form.php
name, phone, url, agent, consent=1, room_id, room_title
```

**Нужна проверка PHP:** после успешного принятия заявки он должен вернуть JSON `{"success":true}`, при отказе — `{"success":false}`. Если сейчас возвращается пустой ответ или HTML, измените ответ в существующей успешной/ошибочной ветке. Не возвращайте успех до обработки заявки. Заголовок ответа: `Content-Type: application/json; charset=utf-8`.

Если название номера нужно менеджеру, добавьте `room_title` в текст письма с серверной проверкой/экранированием. Старый PHP может игнорировать новые поля. Серверная проверка данных, согласия и защита от спама остаются ответственностью обработчика.

В GitHub-демке включён `demo`: она ничего не отправляет. Даже с `live` отправка разрешена только на HTTPS-доменах `www.belokurikha-san.ru` и `belokurikha-san.ru`, на собственный обработчик. На другом домене будет демонстрация.

## 4. Проверка

Открыть форму из разных номеров, проверить выбранное название, закрытие крестиком/Escape/по затемнению и мобильную версию. Пустые поля и отсутствие согласия должны блокировать отправку.

Отправить одну согласованную тестовую заявку и убедиться, что менеджер действительно её получил. Доставку письма из демки проверить нельзя. При неизвестном ответе сервера форма честно сообщает, что результат не подтверждён, и предлагает звонок; повторной автоматической отправки нет.

Откат: убрать одну строку подключения. Старые файлы каталога не заменяются.
