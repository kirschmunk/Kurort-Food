# Страница «Номера» — вариант 2

[Демка второго оформления](https://kirschmunk.github.io/Kurort-Food/belokurikha-room-catalog/variant-2/)

То же содержание и работа карточек, что в первом варианте. Меняется только оформление: мягкие скругления и тени, более лёгкая типографика, разделённые характеристики, контурные кнопки с круглым акцентом. Фото, название поверх нейтрального затемнения, голубой эффект наведения, описания и галереи сохранены. Шапки, цен, карусели и поп-апа бронирования нет.

## Установка

1. Скопируйте **всю родительскую папку `belokurikha-room-catalog`**, включая `assets`, общие CSS, данные, `catalog.js` и эту папку `variant-2`, в `/upload/` сайта. Одной папки `variant-2` недостаточно.
2. В контент страницы вместо первого фрагмента вставьте содержимое **`variant-2/block.html`**. Оба фрагмента одновременно на одну страницу не вставляйте.
3. Если CSS/JS подключаете через шаблон, порядок стилей: `base.css` → `photo.css` → `catalog.css` → `variant-2/refined.css`. Скрипты: `rooms-data.js` → `catalog.js`. Пути и `data-rooms-base` уже прописаны в `block.html`.
4. Подключение вашего поп-апа к кнопке бронирования, расположение в колонке сайта и остальные детали — в [основной инструкции](../README.md). Механизм бронирования не менялся: событие `belokurikha:book-room` передаёт `{id, title}` и само не создаёт бронь.

`index.html` — демка; для сайта нужен `block.html`. Все фотографии и шрифты находятся в родительской папке и поставляются вместе с исходниками. Первый вариант страницы не изменён.

## Проверка

03.11.2026: проверены размеры браузера 320, 390, 768 и 1440 px — соответственно 1, 1, 2 и 4 колонки, без горизонтального переполнения и обрезанных названий/значений. Проверены открытие окна по названию и фото, переключение галереи, Escape и отдельная кнопка бронирования без поп-апа. Ошибок JavaScript не обнаружено. Все 18 записей, файлы фотографий и общий обработчик сохранены; два оформления проходят общую проверку исходников.
