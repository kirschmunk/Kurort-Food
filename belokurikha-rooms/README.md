# Белокуриха — слайдер номеров

[Открыть демку](https://kirschmunk.github.io/Kurort-Food/belokurikha-rooms/)

Блок для главной страницы: четыре карточки на широком экране, листание стрелками, прокрутка пальцем, просмотр двух фотографий каждого номера. Без цен, автоматического перелистывания, форм и сторонних библиотек. Шрифт Acrom и голубой акцент `#289cd8` соответствуют действующему сайту санатория.

## Установка

1. Скопируйте папку `belokurikha-rooms` из архива в `/upload/` рабочего сайта. Должны открываться `/upload/belokurikha-rooms/rooms.css`, `rooms-data.js`, `rooms.js` и папка `assets/`.
2. Вставьте всё содержимое `block.html` в шаблон главной страницы в месте нового блока. Для PHP-шаблона HTML вставляется вне `<?php … ?>`. Не заменяйте шапку, футер и остальные скрипты сайта.
3. Если CMS удаляет `<link>` и `<script>`, подключите `rooms.css` в `<head>` после основных стилей, а оба скрипта — внизу страницы, сохранив их порядок и атрибуты. Сам `<section>…</section>` оставьте на месте блока.
4. Очистите кэш страницы и проверьте фотографии, кнопки, мобильную версию и переход «Все номера».

Рекомендуемое место — после знакомства с санаторием и перед подробными разделами о лечении. Блок имеет собственный контейнер: максимум 1248 px с боковыми отступами по 24 px, полезная ширина 1200 px. Вставляйте в полноширинную область, не в узкую колонку.

При другом каталоге загрузки замените `/upload/belokurikha-rooms/` во всём `block.html`, включая `data-rooms-base`. В CSS пути к файлам относительные, их менять не нужно.

## Что входит

- `block.html` — готовый фрагмент для вставки, с подключениями.
- `rooms.css` — изолированные стили с префиксом `br-rooms`, адаптация, анимация фотографий.
- `rooms.js` — листание и окно фотографий.
- `rooms-data.js` — данные для окна фотографий.
- `assets/images/` — 16 фотографий, по две на каждый номер, сохранённых с официального портала.
- `assets/fonts/` — два шрифта Acrom. У них отдельное имя, шрифт сайта не переопределяется.
- `index.html` — отдельная демка для проверки; её целиком в шаблон вставлять не нужно.
- `rooms-data.json` — исходные названия, характеристики и адреса фотографий для сверки.

Все нужные файлы есть в архиве. Node.js и сборка для установки не требуются. Код не отправляет данные, не подключает аналитику и не меняет контент других блоков. Единственный внешний переход — официальный каталог номеров.

## Поведение

- Более 1100 px: 4 карточки; 851–1100 px: 3; 581–850 px: 2; до 580 px: одна карточка и край следующей.
- Стрелки листают по одной видимой группе. На краях списка соответствующая стрелка отключена.
- Фото и «Подробнее о номере» открывают окно с двумя фотографиями и характеристиками. Это не кнопка бронирования. Из окна можно перейти к официальному каталогу.
- Клавиатура: Tab для перехода по элементам, Enter для кнопок, стрелки в фокусе карусели для листания, Escape закрывает окно. После закрытия фокус возвращается к исходной кнопке.
- При системной настройке уменьшения движения плавные анимации выключены.

## Данные и обновление

Источник: [каталог номеров «Белокурихи»](https://belokurikha.ru/nomera-belokuriha/), проверен 29.10.2026. Переход с [официального сайта санатория](https://www.belokurikha-san.ru/room/) ведёт на этот каталог.

В некоторых старых промостраницах характеристики отличаются. В блоке использованы сведения выбранной записи каталога с конкретным ID и её собственные фотографии. Например, для «Семейного» ID 2299 каталог указывает 37 м²; на отдельных лендингах встречается 34 м². Перед установкой на рабочий сайт владельцу номерного фонда стоит подтвердить актуальность характеристик выбранных записей.

Для ручного изменения названия, мест или площади обновите соответствующую карточку в `block.html` и ту же запись в `rooms-data.js`. `index.html` — отдельная демка; её при необходимости также обновите. Для разработчика в репозитории доступен генератор `tools/build-belokurikha-rooms.cjs`, который пересобирает обе HTML-версии из данных и выбора категорий.

## Финальная проверка на сайте

Проверьте ширины 1440, 1024, 768 и 390 px; открытие и закрытие фотографий, переключение миниатюр; отсутствие горизонтальной прокрутки всей страницы; неизменность меню, шапки и футера. Отдельная демка проверяется автономно: совместимость с глобальными стилями конкретного PHP-шаблона нужно подтвердить после вставки на тестовую страницу.
