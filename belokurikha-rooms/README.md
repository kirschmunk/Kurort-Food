# Белокуриха — слайдер номеров

[Вариант 1 — классические карточки](https://kirschmunk.github.io/Kurort-Food/belokurikha-rooms/) · [Вариант 2 — акцент на фотографиях](https://kirschmunk.github.io/Kurort-Food/belokurikha-rooms/variant-2/)

Два оформления одного блока с одинаковыми данными. В первом варианте название и характеристики находятся под фотографией. Во втором название расположено поверх большого снимка, а три характеристики — компактной строкой ниже; при наведении карточка слегка поднимается, нижняя часть получает голубой оттенок. В обоих вариантах убраны нижняя полоса прокрутки и счётчик «1–4 из 15», стрелки сохранены.

Затемнение фотографии во втором варианте нейтральное тёмное, без синего оттенка. Прозрачность и расположение градиента сохранены; голубые акценты и подсветка нижней части карточки при наведении не изменены.

Блок для главной страницы: 15 вариантов размещения, четыре карточки на широком экране, листание стрелками рядом с заголовком, прокрутка пальцем. В окне «Подробнее о номере» — полное описание, параметры и до пяти фотографий из соответствующей карточки действующего каталога. Раздел «Оснащение номера» во всех окнах отсутствует: список оснащения остаётся только в официальном каталоге «Номера и цены». Без цен, автоматического перелистывания, форм и сторонних библиотек. Шрифт Acrom и голубой акцент `#289cd8` соответствуют действующему сайту санатория.

## Установка

1. Скопируйте папку `belokurikha-rooms` из архива в `/upload/` рабочего сайта. Должны открываться `/upload/belokurikha-rooms/rooms.css`, `rooms-data.js`, `rooms.js` и папка `assets/`.
2. Выберите одно оформление: вставьте всё содержимое `block.html` для первого варианта или `variant-2/block.html` для второго. Не вставляйте оба на одну страницу: они используют общие идентификаторы. Для PHP-шаблона HTML вставляется вне `<?php … ?>`. Не заменяйте шапку, футер и остальные скрипты сайта.
3. Если CMS удаляет `<link>` и `<script>`, подключите `rooms.css` в `<head>` после основных стилей; для второго варианта сразу после него подключите `variant-2/variant.css`. Оба скрипта разместите внизу страницы, сохранив их порядок и атрибуты. Сам `<section>…</section>` оставьте на месте блока.
4. Очистите кэш страницы и проверьте фотографии, кнопки, мобильную версию и переход «Все номера».

Рекомендуемое место — после знакомства с санаторием и перед подробными разделами о лечении. Блок рассчитан на основную колонку сайта `.wrapper`: максимум 1200 px. Вставляйте содержимое `block.html` внутрь этой колонки, не в боковую колонку. Внутри `.wrapper` собственные боковые отступы блока обнуляются, поэтому заголовок и карточки совпадают с краями соседних разделов. Если блок вставлен в полноширинную область без `.wrapper`, он самостоятельно ограничивается 1200 px; на экранах до 1200 px получает по 10 px боковых отступов, как на текущем сайте. Дополнительные обёртки с горизонтальными отступами не нужны.

При другом каталоге загрузки замените `/upload/belokurikha-rooms/` во всём `block.html`, включая `data-rooms-base`. В CSS пути к файлам относительные, их менять не нужно.

## Что входит

- `block.html` — готовый фрагмент для вставки, с подключениями.
- `variant-2/block.html` — готовый фрагмент второго варианта; использует те же фотографии, данные и скрипты.
- `variant-2/variant.css` — дополнительные стили второго варианта.
- `variant-2/index.html` — отдельная демка второго варианта.
- `rooms.css` — изолированные стили с префиксом `br-rooms`, адаптация, анимация фотографий.
- `rooms.js` — листание и окно фотографий.
- `rooms-data.js` — данные для окна фотографий.
- `assets/images/` — 74 оригинальные фотографии с официального портала: по пять на номер, у одноместного «Стандарта» — все четыре доступных фотографии. Фотографии не генерировались и не ретушировались.
- `assets/fonts/` — два шрифта Acrom. У них отдельное имя, шрифт сайта не переопределяется.
- `index.html` — отдельная демка для проверки; её целиком в шаблон вставлять не нужно.
- `rooms-data.json` — исходные названия, характеристики и адреса фотографий для сверки.
- `catalog-snapshot.json` — сверенный снимок всех 15 записей: полные тексты, оснащение, параметры, примечания и адреса всех фотографий исходных галерей, включая не вошедшие в демку. Без цен.

Все нужные файлы есть в архиве. Node.js и сборка для установки не требуются. Код не отправляет данные, не подключает аналитику и не меняет контент других блоков. Единственный внешний переход — официальный каталог номеров.

## Поведение

- Более 1100 px: 4 карточки; 851–1100 px: 3; 581–850 px: 2; до 580 px: одна карточка и край следующей.
- Стрелки листают по одной видимой группе. На краях списка соответствующая стрелка отключена.
- Фото и «Подробнее о номере» открывают окно с галереей, полным названием, описанием, характеристиками и примечаниями из официального каталога. Список оснащения не выводится. Это не кнопка бронирования. Из окна можно перейти к официальному каталогу.
- Фотографии переключаются стрелками поверх снимка, миниатюрами или клавишами влево/вправо при фокусе внутри галереи. После последнего снимка открывается первый. В демке взяты первые пять оригиналов в порядке исходной галереи; если доступно меньше — все доступные.
- Длинное содержимое окна прокручивается, кнопка закрытия остаётся сверху. На компьютере фотогалерея сохраняется рядом с описанием, на телефоне блоки идут друг за другом.
- Компактное окно: описание идёт сразу после названия и типа номера. Площадь, основные и дополнительные места, вместимость, вид из окна, тип кровати и детская кроватка собраны ниже в одном двухколоночном блоке «Характеристики». На телефоне длинные текстовые характеристики занимают всю строку, а короткие показатели остаются в двух колонках. Значения находятся непосредственно под подписями; отдельной растянутой таблицы мест больше нет. Эти сведения сохранены без изменений. Максимальная ширина окна — 1080 px.
- Центрирование окна и шрифты его описания явно заданы внутри компонента: глобальный сброс `margin: 0` и типографика `.blk-content` на сайте их не переопределяют. Кнопки закрытия и листания фотографий имеют область нажатия не менее 44 × 44 px.
- Клавиатура: Tab для перехода по элементам, Enter для кнопок, стрелки в фокусе карусели для листания, Escape закрывает окно. После закрытия фокус возвращается к исходной кнопке.
- При системной настройке уменьшения движения плавные анимации выключены.

### Обновление исходников

Для ручного изменения сначала обновите `catalog-snapshot.json`, затем выполните `node tools/build-belokurikha-rooms.cjs`. Генератор пересобирает `index.html` и `block.html` для обоих вариантов, `rooms-data.json` и `rooms-data.js`, сохраняя тексты исходного снимка.

Для свежей сверенной HTML-выгрузки каталога: `node tools/extract-belokurikha-rooms.cjs <путь-к-HTML>`. Сначала подтвердите в браузере, какие записи сейчас видны посетителю: в HTML есть скрытые старые номера, автоматически добавлять их нельзя. Загрузка оригиналов: `node tools/download-belokurikha-room-images.cjs`. После проверки выполните `node tools/package-belokurikha-rooms.cjs`. Для обычной установки блока эти действия не требуются — архив уже содержит всё необходимое.
