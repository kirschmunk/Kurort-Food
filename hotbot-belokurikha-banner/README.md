# Баннер Hotbot для сайта санатория «Белокуриха»

Готовый адаптивный блок со ссылкой на онлайн-витрину:
https://shop.hotbot.ai/belokurikhasan

## Состав комплекта

- `banner.html` — HTML-фрагмент для вставки в страницу.
- `banner.css` — стили блока, изолированные префиксом `.hotbot-banner`.
- `assets/hotbot-spa.jpg` — оптимизированная фотография.
- `index.html` — автономная страница для предпросмотра; в рабочую страницу её целиком вставлять не нужно.

Блок не использует JavaScript и внешние библиотеки.

## Установка

1. Скопировать папку `assets` и файл `banner.css` в проект сайта, сохранив их взаимное расположение.
2. Подключить стили в `<head>` страницы:

   ```html
   <link rel="stylesheet" href="/путь-к-баннеру/banner.css">
   ```

3. Вставить содержимое `banner.html` в нужное место страницы.
4. Если структура каталогов на сайте отличается, скорректировать только путь `src` у изображения.

## Размеры и адаптивность

- Ширина блока: `100%`, но не более `1196px` — соответствует рабочей ширине контента сайта «Белокуриха».
- Центрирование выполняется внутри самого компонента.
- На экранах до `700px` блок становится одноколоночным, а фотография переносится под текст.
- Фотография оптимизирована до `1024 × 683 px`, размер файла около `52 КБ`.

## Важно для интеграции

Все рабочие селекторы ограничены корневым классом `.hotbot-banner`. Стили компонента не меняют `body`, `header`, общие контейнеры сайта или другие элементы страницы.

Если на странице уже используется идентификатор `hotbot-banner-title`, его нужно заменить одновременно в атрибутах `id` и `aria-labelledby`.
