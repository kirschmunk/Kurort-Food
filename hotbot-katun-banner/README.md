# Баннер HotBot для сайта санатория «Катунь»

Готовый адаптивный блок со ссылкой на онлайн-витрину:
https://shop.hotbot.ai/katunsan

## Состав комплекта

- `banner.html` — HTML-фрагмент для вставки в страницу.
- `banner.css` — изолированные стили блока.
- `assets/hotbot-spa.jpg` — оптимизированная фотография.
- `index.html` — автономная страница для предпросмотра.

## Установка

1. Скопировать папку `assets` и файл `banner.css` в проект сайта.
2. Подключить `banner.css` в `<head>` страницы.
3. Вставить содержимое `banner.html` в нужное место страницы.
4. При другой структуре каталогов изменить только путь `src` у изображения.

Ширина блока ограничена `1196px`. На экранах до `700px` блок становится одноколоночным. Все рабочие селекторы изолированы корневым классом `.hotbot-banner`.
