# Иконка MAX — исправление для двух сайтов

Подходит для уже установленных баннеров «Белокурихи» и «Катуни». Меняется только иконка: текст, телефоны, ссылки MAX, цвета и расположение элементов остаются прежними.

[Скачать исправление и эту инструкцию одним архивом](https://kirschmunk.github.io/Kurort-Food/hotline-max-fix/hotline-max-fix.zip)

## Быстрая установка

1. Скачать [max-icon-fix.css](https://kirschmunk.github.io/Kurort-Food/hotline-max-fix/max-icon-fix.css) и загрузить на сервер сайта **Белокурихи** в `/temp-hotline/max-icon-fix.css`.
2. На **обоих сайтах**, сразу после подключения существующих стилей баннера, добавить одну строку:

```html
<link rel="stylesheet" href="https://www.belokurikha-san.ru/temp-hotline/max-icon-fix.css?v=20261109">
```

На «Белокурихе» эта строка должна быть после `styles.css`, на «Катуни» — после `styles-katun.css`. Остальной HTML и CSS не заменять. Оба сайта уже используют стили из общей папки `/temp-hotline/` на сайте «Белокурихи».

3. Сбросить кеш сайта, если он включён, и обновить страницу. Проверить значок слева от надписи «Написать в MAX» на обоих сайтах, в том числе на телефоне.

**Если удобнее не подключать дополнительный файл:** вставить всё содержимое `max-icon-fix.css` в самый конец **обоих** существующих файлов `/temp-hotline/styles.css` и `/temp-hotline/styles-katun.css`, затем изменить параметр версии в ссылках на эти CSS. Использовать один из этих способов, не оба.

Иконка встроена прямо в CSS; отдельный SVG загружать и настраивать путь к нему больше не нужно. В исправлении только ASCII-символы, поэтому оно подходит и для Windows-1251 страницы «Катуни».

## Что сломалось

Проверено 9 ноября 2026 года: оба CSS запрашивают `/temp-hotline/assets/max-logo.svg?v=2` на сайте «Белокурихи». Вместо SVG сервер отдаёт HTML с перенаправлением на `/404` (несмотря на статус HTTP 200). Поэтому место под значок есть, а самого значка нет. Исправление убирает зависимость от этого пути.
