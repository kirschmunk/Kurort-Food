# Питание «Катунь»: установка без JavaScript

В GitHub — готовая разметка, изолированные стили и ресурсы. Вкладки и фотографии переключаются средствами HTML/CSS. Скрипты, библиотеки и сборка на сайте не нужны. Все 12 иконок — обычные PNG через `img`, без SVG/path.

## Что сделать

1. Удалить прежний фрагмент страницы питания «Катунь» и прежний блок её стилей из общего CSS. Это важно: старые правила для `body`, `h2`, `p` и других общих элементов продолжат влиять на сайт, если оставить их рядом с новым кодом. Остальные стили сайта не удалять.
2. Загрузить папку `assets` по адресу `/upload/katun-food/assets/`, сохранив имена файлов и подпапки `fonts` и `icons`. Если фотографии уже заменены в CMS, сначала сохранить их URL и перенести в новую разметку; не заменять утверждённые фотографии демонстрационными.
3. Добавить всё содержимое `katun-food.css` в конец общего CSS сайта.
4. В HTML-режиме редактора страницы вставить всё содержимое `katun-food.html` вместо старого блока. Вставлять один экземпляр блока на страницу.
5. Сохранить страницу, очистить кеш CSS сайта и обновить страницу браузера.

Если ресурсы размещаются в другой папке, заменить `/upload/katun-food/assets/` на нужный абсолютный путь в обоих файлах — HTML и CSS. Пример: `/images/food/katun/`.

## Что важно сохранить в HTML

Редактор должен сохранять `input type="radio"`, `label`, `fieldset`, `legend`, `img`, а также атрибуты `class`, `id`, `name`, `for`, `checked` и `aria-*`. Переключатели radio визуально скрыты, но остаются доступны с клавиатуры: Tab переводит фокус в группу, стрелки выбирают вариант или фотографию. Пара `input` + следующий `div.kfn-photo-slide` должна оставаться соседними элементами: не вставлять между ними абзац или дополнительную обёртку.

Если CMS вырезает эти теги, вставить код через режим исходного HTML или HTML-компонент. JavaScript для этого решения не требуется. Возможность сохранения тегов нужно проверить в самой админке.

## Почему стили не затронут остальной сайт

Каждый CSS-селектор начинается с `.kfn-page`; все классы, идентификаторы, имена групп и CSS-переменные имеют префикс `kfn-`. Нет общих правил для `html`, `body`, `:root` или заголовков вне блока. Шрифт зарегистрирован под отдельным именем `KatunFoodAcrom` и применяется только внутри блока.

Внешняя страница сама задаёт заголовок H1, шапку, подвал и ширину колонки. Блок занимает доступную ширину контейнера; внутренние перестроения зависят от ширины самого блока.

## Почему на pitanie-new.html сейчас видно весь раздел «О санатории»

При проверке 28.09.2026 сервер отдавал сначала «О санатории», «Сервисные услуги», старое «Питание», «Необходимые документы» и только затем новый `.kfn-page`. Это не проблема ширины или стилей нового блока.

Для `/about/pitanie-new.html` нужно настроить вывод одной записи/страницы, а не списка материалов всего раздела. Сохранить общую шапку, меню, контейнер и подвал, а внутри контейнера вывести H1 «Питание в санатории „Катунь“» и новый фрагмент один раз. Проверить привязку URL к записи и шаблон детальной страницы. Конкретное имя настройки/файла зависит от CMS; без доступа к её конфигурации его нельзя определить по публичной странице.

Не удалять другие страницы раздела и не скрывать их через `display:none`. Если запись уже отдельная, проверить, не скопировано ли в её тело содержимое всего раздела.

## Если стили «применились не полностью»

В проверенном браузере у `.kfn-treatment-grid` было `display:block` вместо `grid`, у `.kfn-page` — общий шрифт сайта вместо `KatunFoodAcrom`. В доступных таблицах CSS домена не было правил `kfn-`. Значит, нужно прежде всего проверить доставку правильного CSS, а не добавлять `!important` ко всем правилам.

1. В DevTools → Network открыть реально загруженный общий CSS (страница подключает, в частности, `/css/main.css`). Найти в ответе `.kfn-page` и `.kfn-photo-state:checked + .kfn-photo-slide`.
2. Если правил нет — содержимое `katun-food.css` добавлено не в тот файл, не опубликовано или выдаётся старая копия из кеша. Добавить его в конец подключённого файла, вне чужих комментариев и `@media`, обновить версию ссылки на CSS/сбросить кеш CMS/CDN.
3. Если правила есть — проверить в Computed, что `.kfn-treatment-grid` имеет `display:grid`, а `.kfn-icon-image` — ширину 25/27 px. При перечёркнутом правиле посмотреть конкретный конкурирующий селектор.
4. Все PNG и WOFF должны отвечать 200. Для иконок используются `assets/icons/*.png`; разрешать SVG в редакторе не требуется.

## Как добавить больше фотографий

### Для текущей установки — ничего добавлять вручную не нужно

Все места для фото уже подготовлены и заполнены заглушками: «Люкс» — 12 кадров, премиум-питание — 9, шведский стол — 9, лечебные диеты — 5, «Ресторан и блюда» — 7. Всего 42 кадра.

Самый простой способ установить свои фото: заменить файлы `assets/photos/premium/01.jpg` … `09.jpg`, `assets/photos/lux/01.jpg` … `12.jpg`, `assets/photos/buffet/01.jpg` … `09.jpg` и файлы в папках `diet` и `gallery`, сохранив имена. Это должны быть JPEG. После загрузки очистить кеш изображений. Порядок соответствует именам файлов. Сборка, изменение `input`, `label`, стрелок и счётчиков для этого не нужны.

В HTML перед каждым кадром есть комментарий «Фото N из M, раздел». Если фото уже загружены в другое место, заменить только `src` и `alt` у следующего `img`. Не менять идентификаторы переключателей и атрибуты `for`. У заглушек намеренно стоит временное описание — заменить его на описание окончательного фото.

Фотографии-заглушки повторяются: они нужны для проверки всех позиций. Финальные фотографии из Google Drive автоматически не подгружаются. Подменять их ссылками на страницу просмотра Google Drive нельзя — нужен прямой адрес файла, доступный без входа в аккаунт, либо загрузка на сайт.

### Если позже потребуется изменить именно количество

Ограничения в 3–4 фото в новой версии нет. Раньше столько кадров было заведено в разметке, а CSS содержал отдельные состояния до четвёртого кадра. Теперь правило переключения одно для любого числа кадров. Сами новые фотографии нужно добавить — дополнительные файлы в папке автоматически в галерею не попадут.

Удобный способ для разработчика: в `galleries.json` добавить объекты `{"src":"https://ваш-сайт/фото.jpg","alt":"Описание фото"}` в `photos` нужной группы (`premium`, `lux`, `buffet`, `diet`, `gallery`), затем локально выполнить:

```sh
node katun-food/build.cjs
node katun-food/test.cjs
```

В CMS заменить `katun-food.html` результатом сборки. При переходе со старой версии один раз заменить и CSS; при последующем добавлении фото CSS менять не нужно. Это инструменты подготовки исходников, на сервере сайта Node.js и JavaScript не нужны.

Можно править HTML вручную: добавить пару `input.kfn-photo-state` + `div.kfn-photo-slide`, задать уникальный `id`, сохранить общее `name` галереи, обновить `for` стрелок/номеров и счётчики. Только один radio группы должен иметь `checked`. Не оборачивать каждую пару в дополнительный контейнер.

## Приёмка

- Заголовки, абзацы, ссылки и кнопки за пределами страницы питания выглядят как до установки.
- Все четыре варианта питания открываются; фотографии переключаются стрелками и номерами.
- Переключение работает при отключённом JavaScript, в том числе с клавиатуры.
- Картинки и шрифт загружаются; в узкой колонке и на телефоне нет горизонтальной прокрутки страницы.
- Ссылки «Путёвки и цены» и телефон доступны.
