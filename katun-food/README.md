# Страница «Питание» санатория «Катунь»

Самостоятельная адаптивная демо-страница по структуре страницы питания «Сибирь», с текстом из предоставленного документа «Катунь текст на сайт». Основные цвета адаптированы к спокойной зелёной палитре санатория.

## Файлы

- `index.html` — страница и интерактивные вкладки/галерея.
- `assets/` — локальные изображения и шрифты Acrom.
- `test.cjs` — проверка текста, ссылок, иконок и локальных файлов.

Откройте `index.html` для просмотра. Для интеграции в сайт используйте содержимое `<main class="katun-food-page">…</main>` и CSS из `<style>`; скрипт внизу страницы управляет переключением форматов и галереей.

Кнопка «Путёвки и цены» ведёт на официальный раздел санатория, телефон — на бесплатный номер бронирования. Изображения показывают соответствующие блюда, ресторан, шведскую линию и выпечку; перед публикацией на официальном сайте их можно заменить утверждённой фотосъёмкой «Катуни».
