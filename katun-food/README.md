# Питание в санатории «Катунь»

Адаптивная страница с утверждёнными текстами и спокойной зелёной палитрой. Вкладки и фотогалереи работают без JavaScript. Стили изолированы внутри `.kfn-page` и подходят для добавления в общий CSS сайта.

- [Демо](https://kirschmunk.github.io/Kurort-Food/katun-food/)
- [Готовые HTML и CSS для вставки](cms/)
- [Инструкция](INTEGRATION.md)

## Для установки

Использовать `cms/katun-food.html` и `cms/katun-food.css`; папку `assets/` загрузить на сайт по инструкции. В этих файлах уже заданы абсолютные пути `/upload/katun-food/assets/`.

Старый фрагмент и старый блок его стилей нужно заменить целиком. Прежний глобальный CSS, оставленный рядом с новым, продолжит влиять на сайт.

## Для редактирования

- `embed.html` — исходная разметка с относительными путями для демо.
- `styles.css` — изолированные стили; все обычные селекторы начинаются с `.kfn-page`.
- `assets/` — изображения и локальные шрифты.
- `assets/icons/` — 12 PNG-иконок; inline SVG не используется.
- `galleries.json` — списки фотографий без ограничения в 3–4 кадра.
- `gallery.cjs` — генератор HTML галерей без клиентского JavaScript.
- `build.cjs` — собирает `index.html`, файлы `cms/` и ZIP-пакет.
- `test.cjs` — проверяет изоляцию, структуру переключателей, ссылки, ресурсы и отсутствие JavaScript.

После изменений: `node katun-food/build.cjs`, затем `node katun-food/test.cjs` из корня репозитория. На самом сайте Node.js не нужен.

Нативные группы radio позволяют работать мышью и клавиатурой. Блок рассчитан на современные браузеры с CSS container queries. CMS должна сохранять HTML-переключатели и обычные `img`. Настройка отдельного URL/шаблона в CMS описана в инструкции; исходники сами не меняют маршрутизацию сайта.
