# Катунь — рейтинги в существующем футере

[Открыть демо](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/)

[Ещё три варианта размещения: под соцсетями, под подпиской и под логотипом](variants/).

Актуальный вариант по новому заданию: **не перерабатывать футер**. Сохраняются его серый фон, шрифт, зелёные иконки, подписка, логотип, телефоны, юридическая информация. Добавлена только пара компактных плашек на общей линии между контактами и текстом о персональных данных. Без нового заголовка, обводки вокруг пары или дополнительной цветной подложки.

![Расположение рейтингов](preview.png)

## Разработчику: только точечная вставка

1. Подключить [`ratings.css`](ratings.css) после стилей сайта. Все селекторы затрагивают исключительно новые классы `ktfr-*` внутри `#footer`.
2. В действующем шаблоне найти `div#footercontainer` (логотип, MAX, телефон, юридическая информация).
3. Вставить [`ratings.html`](ratings.html) **после закрывающего `div` его родительского `.container`, перед следующей `.container` с `p.policycontainer`**. Новый блок должен быть соседом этих двух контейнеров, не дочерним элементом `#footercontainer`.
4. Существующую разметку и стили футера не заменять. Не трогать Unisender-форму, скрытые поля, обработчики, чаты, рекламную полосу и системные подключения.
5. Заменить содержимое двух `.ktfr-ratings__slot` официальными виджетами Катуни: Яндекс Карты и 2ГИС. Предусмотрен компактный формат 150 × 50 px; слоты выровнены по центру, расстояние 12 px. Плашки переносятся на новую строку, если не хватает ширины. Если фактические виджеты другого размера, изменить размер слотов и iframe согласованно, не масштабировать текст через `transform`.
6. Проверить основной сайт на компьютере и телефоне, включая отсутствие перекрытия фиксированной рекламной полосой.

Точное место вставки:

```html
<div class="container">
  <div id="footercontainer">
    <!-- Существующие логотип, контакты и юридическая информация — без изменений. -->
  </div>
</div>

<!-- Вставить ratings.html здесь. -->

<div class="container">
  <p class="policycontainer">...</p>
  <!-- Остальная существующая разметка — без изменений. -->
</div>
```

**Оценки 5,0 условные.** Плашки в демо показывают только компоновку: это не официальные виджеты и не подтверждённые текущие оценки. Их нельзя переносить на основной сайт как реальные рейтинги. Ссылки ведут на карточки Катуни, не конкурента.

## Что является только демонстрацией

`index.html`, `demo-template.html`, `site-reference.css`, `demo.js` и `assets/` воспроизводят вид существующего футера по сайту на 16.10.2026. На основной сайт эти файлы **не переносить**. В демо подписка не отправляет данные. Фиксированная рекламная полоса и сторонние чаты не включены: это самостоятельные модули, на сайте они остаются без изменений.

Пересборка: `node build.mjs`. Ранее предложенные варианты сохранены по прежним адресам, но для текущего задания использовать только точечную вставку из этой папки.

## Проверено

- Геометрия 10 существующих блоков на настольном экране сверена с живым сайтом: размеры и координаты относительно контейнера совпадают. Нижний текст сдвинут на высоту новой строки — 78 px.
- Ширины 320, 390, 768, 1024 и 1224 px: горизонтальной прокрутки нет; плашки одинакового размера, на самом узком экране располагаются одна под другой.
- Изображения загружаются, ошибок JavaScript нет, демонстрационная подписка не отправляет данные.
