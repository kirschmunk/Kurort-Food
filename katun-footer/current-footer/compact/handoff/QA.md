# Проверка комплектов — 20.10.2026

- Сверена публичная разметка главной страницы katun-san.ru. Серверный PHP/CMS-шаблон не предоставлен; точный путь файла не выдумывался.
- Программно проверено сохранение всех семи исходных социальных ссылок и их атрибутов, в том числе двух скрытых. Изменения ограничены левой колонкой: после обратной подстановки исходного блока получается побайтово тот же декодированный документ.
- В установочном HTML нет форм, скриптов и демонстрационных оценок. Новый CSS ограничен #footer .ktfc.
- HTML и CSS содержат только ASCII; русские надписи HTML переданы числовыми сущностями. Учтена объявленная на действующем сайте кодировка Windows-1251.
- Справочное сравнение 03-changes.diff применено к before-reference.html в отдельной временной папке; результат совпал с 01-replace-block.html. Это проверка сравнения фрагментов, не обещание автоматической установки на неизвестный серверный шаблон.
- Оба установочных фрагмента проверены в локальной копии существующего футера на ширинах 320, 390, 768, 1224 и 1440 px. Пять соцсетей видимы, две скрыты; два места для плашек имеют размер 150 × 50 px; нет горизонтального переполнения или наложения на соцсети и подписку. Русский заголовок читается корректно.
- Штатная подписка не отправлялась. Основной сайт не изменялся.

Официальные виджеты пока не переданы. Проверены временные ссылки и контейнеры, а не внешние iframe/script, загрузка живых рейтингов, CSP основного сайта или итоговая установка в CMS. После вставки настоящих кодов требуется повторная проверка в рабочем шаблоне. Самостоятельные прогоны в Safari и Firefox не выполнялись.

Для повторной подготовки: сохранить публичную страницу в её исходной кодировке и запустить `node ../build-handoff.mjs /path/to/snapshot.html`. Этот генератор нужен только при подготовке комплекта, не на сервере санатория.
