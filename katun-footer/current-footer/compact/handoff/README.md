# Два готовых комплекта для разработчика

Меняется только левая колонка футера с соцсетями. Остальной футер и подписка остаются в существующем шаблоне.

| Вариант | Скачать комплект | Инструкция |
| --- | --- | --- |
| 1. Соцсети и рейтинги в одну линию | [ZIP](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/compact/handoff/katun-footer-variant-1.zip) | [Читать](inline/README.md) |
| 2. Две группы — соцсети и отзывы | [ZIP](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/compact/handoff/katun-footer-variant-2.zip) | [Читать](columns/README.md) |

В архиве сначала открыть **START-HERE.html** или **README.md**.

Три действия: заменить указанный HTML-блок, подключить один CSS-файл и вставить официальные коды Яндекс Карт и 2ГИС в отмеченные места. Никаких сборщиков и зависимостей на сервере не требуется.

Сейчас в установочных файлах — временные ссылки на отзывы без оценок. Официальные коды виджетов заказчик пока не предоставил. Согласованные демонстрационные страницы и их внешний вид не менялись.

Разметка сверена с katun-san.ru 20.10.2026; сохранены все семь социальных ссылок, включая две скрытые. Учтена кодировка Windows-1251. [Проверки и ограничения](QA.md).
