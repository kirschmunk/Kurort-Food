# Ещё три размещения рейтингов

Все варианты используют один и тот же существующий футер Катуни: цвета, фон, соцсети, подписка, логотип, контакты и юридический текст сохранены. Отличается только место нового блока из двух плашек. В первых двух вариантах новая строка естественно увеличивает высоту верхней части футера; элементы не переставлены.

| Вариант | Демо | Точечная вставка |
| --- | --- | --- |
| 1. Под социальными иконками | [Открыть](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/variants/social/) | [Исходники](social/) |
| 2. Под формой подписки | [Открыть](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/variants/subscribe/) | [Исходники](subscribe/) |
| 3. Внизу слева, под логотипом | [Открыть](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/variants/logo/) | [Исходники](logo/) |

Вариант 1 группирует отзывы с социальными каналами. Вариант 2 освобождает левую часть и собирает плашки под подпиской справа. Вариант 3 сохраняет положение верхних блоков и выравнивает новую нижнюю строку по левому краю логотипа.

Выбрать **один** вариант. В каждой папке свои `ratings.html`, `ratings.css` и инструкция с точным местом вставки. Остальной футер не заменять. На страницах нет демонстрационных шапок и дисклеймеров. Оценки 5,0 условные — до внедрения заменить плашки официальными виджетами Катуни.

[Ранее предложенное размещение по центру внизу](https://kirschmunk.github.io/Kurort-Food/katun-footer/current-footer/) сохранено без изменений.

Сборка: `node build.mjs` из этой папки. Генератор проверяет, что после удаления нового блока исходная разметка каждого футера совпадает с базовой и что новые стили не затрагивают существующие элементы.

Проверено в браузере на ширинах 320, 390, 768 и 1224 px: обе плашки сохраняют размер 150 × 50 px, не перекрывают существующие блоки и не вызывают горизонтальную прокрутку. На узких экранах пара переносится при необходимости. Изображения загружаются.
