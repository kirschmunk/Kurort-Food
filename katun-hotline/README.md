# Баннер горячей линии санатория «Катунь»

[Открыть демку](https://kirschmunk.github.io/Kurort-Food/katun-hotline/)

Готовый адаптивный блок с телефоном и MAX. Компоновка такая же, как в согласованном баннере «Белокурихи»: белый фон, аккуратная рамка, текст слева, две кнопки справа. Акценты зелёные, в стилистике «Катуни». Без JavaScript, внешних библиотек и отправки данных.

Версия 2: значок MAX встроен в CSS и не зависит от пути к папке картинок. Если баннер уже установлен, а значок пропал, используйте [маленькое исправление для обоих сайтов](../hotline-max-fix/) вместо полной замены стилей.

## Установка

1. Скопировать всю папку `katun-hotline` на сайт, например в `/assets/katun-hotline/`. Шрифты входят в комплект: сохранить структуру `assets/fonts`. Чёткий векторный значок MAX уже встроен в CSS; отдельный файл иконки при загрузке страницы не запрашивается.
2. Подключить CSS **после основных стилей сайта**:

```html
<link rel="stylesheet" href="/assets/katun-hotline/hotline.css?v=2">
```

3. Вставить содержимое [block.html](./block.html) в нужное место главной страницы **внутри существующей колонки** `.e1-container`. Блок занимает 100% ширины родителя; не нужно добавлять второй контейнер внутрь первого.

Если баннер размещается отдельной секцией вне существующего контейнера:

```php
<div class="e1-container" style="margin-top: 24px; margin-bottom: 24px;">
  <?php include $_SERVER['DOCUMENT_ROOT'] . '/assets/katun-hotline/block.html'; ?>
</div>
```

Можно просто скопировать HTML-фрагмент в шаблон вместо `include`.

**Кодировка:** файлы комплекта — UTF-8. Если страница сайта выдаётся в Windows-1251, при вставке через редактор сохранить текст в кодировке шаблона. При PHP-подключении отдельного UTF-8-фрагмента использовать вместо `include`:

```php
<?php
echo iconv('UTF-8', 'Windows-1251', file_get_contents(
    $_SERVER['DOCUMENT_ROOT'] . '/assets/katun-hotline/block.html'
));
?>
```

Для страницы в UTF-8 перекодировка не нужна. Не менять кодировку всей действующей страницы ради этого блока.

## Размеры и оформление

Размеры демки повторяют `.e1-container` из [стилей сайта «Катуни»](https://www.katun-san.ru/css/e1-specs.css), проверенных 6 ноября 2026 года:

- Максимальная ширина контейнера — 1260 px, боковые отступы — 30 px; рабочая ширина баннера — **1200 px**.
- До 991 px — контейнер шириной 90% окна с отступами по 20 px.
- До 767 px — 95% окна с отступами по 15 px.
- На широком экране вертикальные отступы баннера — 34 px, высота обеих кнопок — 54 px.
- При ширине блока до 1000 px кнопки переходят под текст; до 760 px занимают всю ширину, до 500 px располагаются одна под другой.
- Зелёный цвет кнопки `#00865a` — немного более тёмный оттенок фирменного зелёного `#009e6a`, чтобы белый текст оставался контрастным и на телефоне. Фон светлый, без синего оттенка.
- Значок MAX сохраняет фирменную сине-фиолетовую палитру. Использован тот же оптимизированный SVG, что в согласованном баннере «Белокурихи»: официальный контур из [брендбука MAX](https://go.max.ru/brandbook), плавный градиент без текстур и размытия.

## В комплекте

- `block.html` — фрагмент для вставки в шаблон.
- `hotline.css` — изолированные стили с префиксом `kt-hotline`.
- `assets/fonts/Acrom-Regular.woff` и `Acrom-Bold.woff` — шрифты.
- `assets/max-logo.svg` — редактируемый исходник векторной иконки MAX (копия встроена в CSS).
- `index.html` — демка; её обёртку `.demo-column` переносить на сайт не нужно.

После установки проверить загрузку CSS, шрифтов и значка MAX, телефон и адрес кнопки MAX, совпадение ширины с соседними блоками и отсутствие горизонтальной прокрутки на мобильном. При необходимости сбросить кеш сайта. Папку баннера «Белокурихи» менять не нужно — версия «Катуни» самостоятельная.
