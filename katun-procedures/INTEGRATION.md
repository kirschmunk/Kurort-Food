# Установка в CMS «Катуни»

1. Создать **отдельную страницу** «Процедуры» в разделе «Лечение». Подключить обычный внутренний шаблон сайта. Не вставлять этот контент в существующую страницу «О санатории». Адрес страницы и её пункт меню настраиваются в CMS, HTML сам их не создаёт.
2. Загрузить всю папку `assets` по адресу **`/upload/katun-procedures/assets/`**. Не менять имена файлов. Если используется другой путь, заменить `/upload/katun-procedures/assets/` одновременно в HTML и CSS.
3. В режиме исходного кода вставить **весь `cms/katun-procedures.html`** в содержимое новой страницы. Отдельный автоматически выводимый H1 шаблона отключить для этой страницы: H1 «Процедуры» уже есть в разметке.
4. Добавить **весь `cms/katun-procedures.css` в конец общего файла стилей**. Это изолированные стили: правил для `body`, `html`, общих `h1`, `p`, `.wrap`, `.button` в них нет. Если обновляете этот раздел, прежний блок `.ktp-page` заменить целиком.
5. Очистить кеш CSS/CMS. Проверить страницу в обычном и приватном окне браузера.

## Важные ограничения редактора

Страница не требует JavaScript, `svg`, `path`, `iframe`, встроенных стилей или обработчиков событий. Редактор должен сохранять обычные `img`, классы, `id`, элементы **`details` и `summary`**. После сохранения проверьте, что эти два элемента не превращаются в текст и не удаляются. Это ещё не проверено в админке официального сайта.

Если CMS удаляет `details/summary`, нужно разрешить эти безопасные теги в фильтре или вставить HTML через шаблон. Не заменять `summary` обычным `div`: без него раскрытие работать не будет. Как запасной статический вариант можно вывести все описания открытым списком, но это отдельное изменение верстки.

## После установки

- Открыть и закрыть все 12 направлений мышью и клавиатурой (Tab, Enter / Space).
- Проверить фотографии, три графических значка и шрифт; в консоли сети не должно быть 404 на `/upload/katun-procedures/assets/`.
- Проверить мобильные размеры 320–390 px и узкую колонку шаблона.
- Проверить кнопки «Познакомиться с врачами», «Стоимость процедур», телефон.
- Убедиться, что стили соседних разделов и меню сайта не изменились.
- Согласовать список из `CONTENT-REVIEW.md` с медицинским отделом до публикации на официальном сайте.

Демонстрационная шапка из `index.html` в CMS не переносится. `styles.css` также содержит стили демошапки; для общего CSS берите именно файл из `cms/`.
