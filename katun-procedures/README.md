# Процедуры санатория «Катунь»

[Открыть демо](https://kirschmunk.github.io/Kurort-Food/katun-procedures/)

Обновление 14 октября 2026: каталог выстроен по направлениям лечения. Косметология и СПА находятся в самостоятельной части страницы. Сохранены все 74 уникальные позиции исходного документа; подробности каждой открываются отдельно, вместе с фотографией или обозначенным местом под будущий снимок.

## Полная страница для разработчика

- [cms/katun-procedures.html](cms/katun-procedures.html) — весь контент для шаблона сайта.
- [cms/katun-procedures.css](cms/katun-procedures.css) — стили для общего файла CSS.
- [assets/](assets/) — готовые фотографии, PNG-значки и шрифты.
- [INTEGRATION.md](INTEGRATION.md) — порядок установки.

Это не точечный патч: HTML заменяет всё содержимое страницы «Процедуры». Шапку, меню, подвал и бронирование выводит шаблон сайта. Самостоятельная версия — `index.html`. На официальном сайте изменения не установлены.

## Структура

1. Направления лечения: ЖКТ, сердце и сосуды, суставы и позвоночник, нервная система, женское здоровье, органы дыхания.
2. Диагностика и общие методики: исследования, аппаратные процедуры, инфузионная терапия, водолечение и оздоровление.
3. Косметология и СПА: отдельный каталог ухода за лицом и телом.

Числа 53 / 12 / 9 отражают уникальные позиции переданного перечня, а не общее число медицинских услуг санатория. Одна лечебная методика может появляться в нескольких подходящих профилях: содержание и фото при этом хранятся в одном месте. Внутри одного раздела повторов нет. Из гастроэнтерологии и кардиологии есть ссылки на диагностические исследования.

Распределение — редакционная навигация на основе документа и профильных страниц санатория, а не перечень обязательных назначений. Перед официальной публикацией требуется медицинское согласование: [CONTENT-REVIEW.md](CONTENT-REVIEW.md).

## Тексты и фотографии

- `content.json` — названия, группы, индексы исходных абзацев DOCX с нуля. Краткие тексты в массиве процедур сохранены для сопоставления с прошлой версией, но больше не выводятся.
- `procedure-details.json` — **все публикуемые подробные описания**. `paragraphs` — абзацы; необязательные `listTitle`, `points`, `note` — этапы и пояснения.
- `photo` — имя JPG без расширения из `assets/photos/`; `photoAlt` — подпись для доступности. Если `photo` не задано или `photoPlaceholder: true`, выводится аккуратная заглушка, а не неподходящая медицинская фотография.
- Для замены заглушки загрузите свой JPG в `assets/photos/`, укажите его имя в `photo`, заполните `photoAlt`, удалите `photoPlaceholder` и пересоберите страницу. Обновите HTML и папку assets на сайте. Один файл данных обновляет все повторные вхождения процедуры.
- Для восьми позиций в документе нет развёрнутого описания — они отмечены `needsDescription: true`. Подробности не выдумывались.

## Сборка и работа

```sh
node katun-procedures/build.cjs
node katun-procedures/test.cjs
```

Редактируйте данные, `build.cjs` и `styles.css`, затем выполняйте сборку. Она обновляет демо, `embed.html` и файлы `cms/`. На сервере Node.js не нужен; готовые файлы можно просто перенести.

Раскрытие — нативные `details/summary`, без JavaScript и inline SVG. Атрибут `name` оставляет открытым один раздел и одно описание в современных браузерах. В старых браузерах может быть открыто несколько — тексты остаются доступными. Все CMS-стили ограничены `.ktp-page`; адаптивность учитывает ширину контейнера. Фотографии не растягиваются по высоте текста.

`prepare-assets.cjs` — необязательная подготовка новых оригиналов, требует `sharp`. Подготовленные изображения уже включены. Результаты и границы проверки — [QA.md](QA.md).
