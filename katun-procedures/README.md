# Процедуры санатория «Катунь»

[Открыть демо](https://kirschmunk.github.io/Kurort-Food/katun-procedures/)

Полная новая страница: 12 направлений, 74 уникальные позиции, реальные фотографии из предоставленных материалов. Описания сокращены и отредактированы для посетителей сайта. Услуги, входящие в путёвку, цены и медицинские назначения не выдумывались.

## Что передать разработчику

- **[cms/katun-procedures.html](cms/katun-procedures.html)** — весь контент страницы для вставки в шаблон сайта.
- **[cms/katun-procedures.css](cms/katun-procedures.css)** — стили для добавления в общий CSS сайта.
- **[assets/](assets/)** — фотографии, PNG-значки и шрифты.
- **[INTEGRATION.md](INTEGRATION.md)** — короткая инструкция установки.

Это не патч: HTML заменяет всё содержимое новой страницы «Процедуры». Шапку, меню, подвал и бронирование добавляет сам сайт. Самостоятельная демоверсия находится в `index.html`.

**До установки:** ознакомьтесь с [CONTENT-REVIEW.md](CONTENT-REVIEW.md). Там перечислены недостающие описания и материалы, требующие согласования. Демо — проект страницы для просмотра, а не подтверждение медицинской корректности и не публикация на официальном сайте.

## Как работает

- Категории открываются обычным HTML-элементом `details` / `summary`, без JavaScript.
- Иконки — обычные PNG. Inline SVG, скриптов, библиотек и слайдеров нет.
- Все правила в CMS-стилях ограничены `.ktp-page`; служебные названия начинаются с `ktp-`.
- Адаптивность зависит от ширины блока, а не только от окна: используются CSS container queries. Проверять в актуальных браузерах с их поддержкой.
- Фотографии оптимизированы для сайта. Оригиналы с Google Drive в репозиторий не добавлены.
- Кнопки ведут на настоящие страницы врачей и прайс-листа; телефон — `tel:`. Заявки эта страница не собирает.

## Исходники и сборка

`content.json` — каталог, краткие описания, группировка. У каждой позиции сохранены индексы исходных абзацев DOCX (с нуля) для редакционной сверки; `needs-description` отмечает позиции без развёрнутого исходного описания.

`build.cjs` формирует `embed.html`, `index.html` и полные файлы `cms/`. На сервере сайта Node.js не нужен.

```sh
node katun-procedures/build.cjs
node katun-procedures/test.cjs
```

Редактируйте тексты в `content.json`, разметку — в `build.cjs`, оформление — в `styles.css`, затем выполняйте сборку. Для простого переноса готовой страницы ничего собирать не требуется.

`prepare-assets.cjs` — необязательная подготовка изображений из исходной папки; требует пакет `sharp`. Нужен только для повторной оптимизации новых исходных фотографий. Все подготовленные изображения уже лежат в `assets/`.
