# Сезон ментального здоровья — макет страницы портала

[Открыть демку](https://kirschmunk.github.io/Kurort-Food/mental-health-portal/)

Интерактивная HTML-версия предоставленного макета Figma. Сохранены исходные композиция, тексты, цвета, шрифт Acrom, фотографии, декоративные элементы и расположение блоков. Это отдельная демка, не изменение действующего портала.

## Состав

- `index.html` — разметка и тексты.
- `styles.css` — оформление и адаптация к узким экранам.
- `script.js` — фотогалерея и окна с контактами / превью видео.
- `assets/figma/` — оригинальные растровые и векторные экспорты элементов Figma.
- `assets/fonts/` — локальные шрифты Acrom.
- `assets/*.webp` — дополнительные фотографии для галереи из материалов пользователя. Внешних библиотек и сборки нет.

Для просмотра достаточно открыть `index.html` в браузере. Для размещения демки скопировать всю папку с сохранением структуры.

## Основа

Макет пользователя в [Figma](https://www.figma.com/design/KoohaTqp05KIhAcQFT3Ysp/Untitled?node-id=3-2), PDF «ментальное здоровье» и предоставленные фотографии. Рабочий размер исходника — 1907 × 6204 px. На настольных экранах страница пропорционально масштабируется по ширине, сохраняя композицию Figma. До 700 px блоки перестраиваются в одну колонку, текст и кнопки остаются читаемыми. Фотографии и SVG из Figma не перерисованы; текст свёрстан отдельно, это не скриншот всей страницы.

## Что работает в демке

Перелистывание 5 фотографий в разделе подарков стрелками, точками и свайпом; окна с телефонами санаториев; телефонные ссылки. Окна закрываются крестиком, клавишей Escape и нажатием на фон. Нижняя фотография программы и её декоративный индикатор повторяют Figma; отдельные слайды для этого блока не предоставлены.

## Перед интеграцией

1. Это макет, а не готовый шаблон CMS. Шапка повторяет растровый элемент из Figma: её меню демонстрационное. При интеграции заменить `.reference-header` штатной шапкой портала; стили изолировать от общих стилей сайта. Подвал в исходном макете отсутствует и не добавлен.
2. Форм отправки заявок нет. CTA открывают контакты санаториев. При интеграции заменить их обработчики на штатную форму / согласованный сценарий бронирования.
3. Передана только обложка видео. Сейчас открывается превью с пояснением; для воспроизведения нужна ссылка на ролик.
4. Даты, перечни процедур, цены и условия взяты из предоставленного макета, не подтверждены как актуальные коммерческие условия. Перед публикацией на действующем сайте их должен согласовать ответственный сотрудник.
5. В исходном макете для «Сибири» одновременно указаны скидка 30% и цена 1000 ₽ вместо 1450 ₽. Эти значения сохранены, но точное соотношение следует уточнить.

Персональные данные не собираются, запросов к CRM / системам бронирования нет.
