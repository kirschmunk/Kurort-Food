# Сезон ментального здоровья — макет страницы портала

[Открыть демку](https://kirschmunk.github.io/Kurort-Food/mental-health-portal/)

Адаптивный интерактивный макет для согласования оформления. Это отдельная страница, не изменение действующего портала.

## Состав

- `index.html` — разметка и тексты.
- `styles.css` — оформление и адаптация к узким экранам.
- `script.js` — фотогалерея и окна с контактами / превью видео.
- `assets/` — фотографии, шрифты, логотип, декоративные элементы из Figma. Внешних библиотек и сборки нет.

Для просмотра достаточно открыть `index.html` в браузере. Для размещения демки скопировать всю папку с сохранением структуры.

## Основа

Макет пользователя в [Figma](https://www.figma.com/design/KoohaTqp05KIhAcQFT3Ysp/Untitled?node-id=3-2), PDF «ментальное здоровье» и предоставленные фотографии. Дизайн адаптирован, это не пиксельная копия исходного макета. Контентная колонка — до 1196 px. Фотографии оптимизированы в WebP; оригиналы не изменены.

## Что работает в демке

Переходы по разделам, перелистывание 7 фотографий стрелками и свайпом, окна с телефонами санаториев, телефонные ссылки. Окна закрываются крестиком, клавишей Escape и нажатием на фон.

## Перед интеграцией

1. Это макет, а не готовый шаблон CMS. Демонстрационные шапку и подвал нужно заменить штатными элементами портала; стили изолировать от общих стилей сайта.
2. Форм отправки заявок нет. CTA открывают контакты санаториев. При интеграции заменить их обработчики на штатную форму / согласованный сценарий бронирования.
3. Передана только обложка видео. Сейчас открывается превью с пояснением; для воспроизведения нужна ссылка на ролик.
4. Даты, перечни процедур, цены и условия взяты из предоставленного макета, не подтверждены как актуальные коммерческие условия. Перед публикацией на действующем сайте их должен согласовать ответственный сотрудник.
5. В исходном макете для «Сибири» одновременно указаны скидка 30% и цена 1000 ₽ вместо 1450 ₽. Эти значения сохранены, но точное соотношение следует уточнить.

Персональные данные не собираются, запросов к CRM / системам бронирования нет.
