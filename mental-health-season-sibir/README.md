# Баннер «Ментальное здоровье» для санатория «Сибирь»

Адаптивный баннер в фирменной коралловой палитре санатория «Сибирь».

Целевая страница: https://sibir-san.ru/sales/mentalnoe-zdorove/

## Файлы

- `banner.html` — готовый фрагмент для вставки.
- `banner.css` — изолированные стили баннера.
- `assets/mental-health-hero.jpg` — оптимизированная фотография.
- `preview.html` — автономный предпросмотр.

## Установка

1. Скопировать `banner.html`, `banner.css` и папку `assets` в каталог блока.
2. Подключить `banner.css` на странице один раз.
3. Вставить разметку из `banner.html` вместо старого баннера.
4. При изменении структуры каталогов скорректировать путь к изображению в `banner.css`.

JavaScript и внешние библиотеки не требуются. Все рабочие селекторы имеют префикс `.mental-season-banner`, поэтому блок не влияет на шапку и другие части сайта.
