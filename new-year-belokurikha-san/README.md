# Новогодние каникулы — санаторий «Белокуриха»

Исходный макет: https://www.figma.com/design/IFJe10TVrIYsDPIN5NhyxV/Untitled--Copy-?node-id=0-1

Демо: `index.html`. Страница предназначена для раздела специальных предложений сайта `belokurikha-san.ru`. Она начинается с периода проведения; шаблонные шапка и первый экран сайта намеренно не включены.

Оставлена только релевантная информация санатория «Белокуриха». Праздничный ужин показан одной статичной карточкой без слайдера. В банкетном слайдере сохранены три банкета санатория «Белокуриха»; блоки «Сибири» и «Катуни» удалены. Общий блок трёх историй преобразован в одну программу «Кино-МульТеатр». Контактный номер приведён к номеру официального сайта: 8-800-707-51-83. Банкетный слайдер работает без клонов, с автолистанием раз в 5 секунд, перетаскиванием мышью/пальцем, стрелками и клавиатурой. Страница рассчитана на контейнер сайта шириной 1200px с мобильными полями 10px; её стили изолированы классом `.new-year-page`.

Перед интеграцией нужны:

- Ссылка на видео для первого блока. Сейчас там заглушка.
- Действие для кнопок «Оставить заявку» — в автономном предпросмотре только пояснение, форма сайта не подключена.
- Ссылки на меню и афиши после размещения файлов на хостинге. Сейчас надписи не кликабельны.
Проверки в `tests/` контролируют состав страницы, отсутствие блоков других санаториев, статичный ужин, банкетный слайдер, точность ключевого текста и совместимость с контейнером сайта.
