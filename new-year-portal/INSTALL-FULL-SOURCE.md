# Полная замена страницы на портале

Этот комплект передаётся как готовая версия страницы. Старую пользовательскую разметку, стили и JavaScript не нужно объединять с новыми файлами или исправлять точечно.

## Что заменить

1. Удалить прежний пользовательский HTML новогодней страницы.
2. Для самостоятельной страницы использовать `index.html`. Для поля HTML в CMS вставить `page-content.html` целиком: в нём только `<main class="new-year-page">…</main>`, без `html`, `head` и `body`. Шапка портала и его шаблонный первый экран в файл намеренно не включены.
3. Полностью заменить прежний CSS страницы файлом `styles.css`.
4. Полностью заменить прежний JavaScript страницы файлом `script.js`.
5. Загрузить каталог `assets` без изменения структуры и имён файлов.
6. Проверить, что пути `./assets/...` разрешаются относительно каталога страницы.
7. Очистить кеш страницы и CDN.

Файлы `styles.css` и `script.js` подключаются отдельно после штатных стилей и скриптов портала. Сохранить установленные на портале URL меню, афиш, фото и заявок: в демо используются исходные ресурсы и резервные ссылки из `newYearLinks` в `script.js`.

Не следует одновременно оставлять прежний CSS или JavaScript новогодней страницы: дублирующиеся правила и обработчики снова вызовут наложение карточек, обрезание теней и двойную работу слайдеров.

## Состав комплекта

- `index.html` — полная разметка контентной части;
- `page-content.html` — полная контентная часть, готовая для вставки в CMS;
- `styles.css` — все стили, включая адаптацию к колонке портала;
- `script.js` — оставшийся слайдер праздничного ужина, кликабельные ссылки и анимация карточек первого блока;
- `assets/` — изображения, фоны и шрифты;
- `README.md` — описание проекта.
- `patch-banquets/` — отдельная точечная правка: инструкция, CSS и HTML только банкетного раздела.

## Контроль после установки

- ширина основного контейнера — не более 1196 px;
- широкие секции имеют скруглённые края и не выходят за колонку;
- тени карточек не обрезаются;
- стрелки находятся по центру под слайдами;
- все 7 банкетов видны друг под другом: 3 / 2 / 2 по санаториям, без навигации, свайпа и автолистания;
- в слайдере праздничного ужина видна одна карточка; его стрелки и автолистание сохранены;
- на странице отсутствует горизонтальная прокрутка.
