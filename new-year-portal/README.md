## Полная замена

Для разработчика: `page-content.html` — вся контентная часть в одном HTML-фрагменте; `styles.css`, `script.js` и `assets/` — полные сопутствующие файлы. `index.html` — самостоятельное демо. Внешние шапка, меню и первый экран портала не входят в контентную часть.

Не объединять старый и новый код страницы. Перед полной заменой сохранить уже установленные на портале URL видео, фотографий, меню, афиш и заявки. В демо видео пока заглушка. Прямые адреса афиш и меню заданы в HTML, работают без JavaScript и ведут на внешний сервер портала. Перед запуском проверьте доступность этих файлов.

## Точечная замена

В `patch-banquets/` лежат инструкция, небольшой дополнительный CSS и готовая разметка только банкетной секции. Можно заменить лишь обёртки вокруг существующих карточек: так сохранятся персональные ссылки разработчика. JavaScript менять не требуется — банкетные блоки больше не имеют атрибутов запуска каруселей.

## Проверки

```sh
node new-year-portal/build.cjs
node new-year-portal/tests/carousel.test.cjs
node new-year-portal/tests/dinner.test.cjs
node new-year-portal/tests/links.test.cjs
node new-year-portal/tests/copy.test.cjs
node new-year-portal/tests/portal.test.cjs
```

Сборка синхронизирует полный HTML-фрагмент, отдельную банкетную секцию, CSS точечной правки и полный архив. Проверки контролируют 7 статичных карточек, оставшийся слайдер ужина, неизменённые тексты, ссылки и ширину портального контейнера до 1196 px. Также выполнена браузерная проверка вертикального порядка, отсутствия перекрытий, теней и мобильной компоновки.

Фотографии банкетов в `assets/demo` оптимизированы для демо. Полноразмерные экспорты разработчик берёт из исходного макета. Источник обновления: [официальная новогодняя страница](https://belokurikha.ru/sales/novyj-god-v-belokurihe-2/).
