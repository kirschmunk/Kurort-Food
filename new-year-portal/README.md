# Новогодние каникулы — контентная часть портала

Для передачи разработчику используйте полный архив `downloads/new-year-portal-full-source.zip`. Установка выполняется полной заменой прежних HTML, CSS и JavaScript страницы; подробности находятся в `INSTALL-FULL-SOURCE.md`.

Исходный макет: https://www.figma.com/design/IFJe10TVrIYsDPIN5NhyxV/Untitled--Copy-?node-id=0-1

Демо: `index.html`. Страница начинается с периода проведения; шаблонные шапка и первый экран портала намеренно не включены.

Сделано: контентный первый блок, три карточки праздничного ужина в отдельном слайдере, банкетные слайдеры (3/2/2 карточки), текстовый блок трёх санаториев без PDF-ссылок, отзывы и блоки заявки. Новые изображения и фоновые узоры из брифа, включая фон «Трёх новогодних историй», лежат в `assets/brief`; для демо иллюстрации банкетов оптимизированы и лежат в `assets/demo`, шрифты размещены локально. Полноразмерные экспорты Figma в репозиторий намеренно не включены: разработчик может взять оригиналы из исходного макета. Все карусели работают без клонов: в покое в DOM отображается ровно одна карточка, соседняя появляется только на время анимации. Карточка уезжает на полную ширину окна слайдера, поэтому её край не остаётся видимым при разнице ширины карточки и контейнера. Предусмотрены автолистание раз в 5 секунд, перетаскивание мышью/пальцем, стрелки и управление с клавиатуры. Текст и изображения при перетаскивании не выделяются, а ссылки и кнопки сохраняют обычный клик. Автолистание приостанавливается, пока пользователь взаимодействует с карточкой. Фон «Трёх новогодних историй» задан один раз для всей секции, вложенной фоновой карточки нет.

Перед интеграцией нужны:

- Ссылка на видео для первого блока. Сейчас там заглушка.
- Действие для кнопок «Оставить заявку» — в автономном предпросмотре только пояснение, форма портала не подключена.
- Ссылки на меню и афиши после размещения файлов на хостинге. Сейчас надписи не кликабельны.
- Уточнение программы банкета «Музыкальный взрыв»: в макете её текст повторяет программу «Золотого руна»; в этой версии он оставлен по макету, без самостоятельного исправления.

Проверено: все локальные ссылки на изображения и шрифты существуют, скрипт проходит проверку синтаксиса. `node tests/dinner.test.cjs` проверяет стартовую карточку ужина, оба направления листания, перетаскивание мышью, автолистание и один фон блока историй. `node tests/carousel.test.cjs` проверяет стартовую карточку, переходы через стык, перетаскивание мышью и автолистание для трёх банкетных каруселей. Визуальная проверка в браузере не выполнена: встроенный браузер заблокировал локальный адрес; внешний опубликованный результат для этой версии ещё не проверялся.
