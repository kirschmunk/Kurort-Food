# Точечная правка: банкеты друг под другом

Только для новогодней страницы портала. Праздничный ужин остаётся слайдером. У банкетов сохраняются карточки, фото, текст, цены и ссылки, но все карточки видны сразу: 3 у «Белокурихи», 2 у «Сибири», 2 у «Катуни».

## 1. Заменить обёртки в HTML трёх групп банкетов

Найти начало слайдера **внутри каждого `.banquet-group`**:

```html
<div class="carousel" data-carousel>
  <div class="carousel-track" tabindex="0" aria-label="Банкеты санатория Белокуриха">
```

Заменить две строки одной:

```html
<div class="banquet-list" role="group" aria-label="Банкеты санатория Белокуриха">
```

Для двух остальных групп в `aria-label` оставить «Банкеты санатория Сибирь» и «Банкеты санатория Катунь». Внутренние `<article class="banquet-card">…</article>` сохранить **без изменений**, вместе с установленными ссылками на меню, афиши, бронирование и фото.

В конце каждого бывшего слайдера найти:

```html
  </div><!-- конец carousel-track -->
  <div class="carousel-controls">
    <button class="carousel-button" data-prev type="button">←</button>
    <button class="carousel-button" data-next type="button">→</button>
  </div>
</div><!-- конец carousel -->
```

Заменить весь этот фрагмент одним закрытием:

```html
</div><!-- конец banquet-list -->
```

У существующих кнопок могут быть дополнительные `aria-label`; навигация удаляется целиком. Закрывающий `</div>` самой `.banquet-group` **оставить**. Итоговая вложенность:

```html
<div class="banquet-group">
  <div class="group-heading"><h2>Новогодние банкеты в санатории «Сибирь»</h2></div>
  <div class="banquet-list" role="group" aria-label="Банкеты санатория Сибирь">
    <!-- Здесь существующая карточка «Тысяча масок и одна ночь» целиком. -->
    <!-- Затем существующая карточка «Золотое руно» целиком. -->
  </div>
</div>
```

Это схема, не замена содержимого карточек. Для замены всего банкетного раздела есть готовый [banquets-section.html](banquets-section.html). Перед такой заменой перенесите реальные URL фотографий, меню и афиш: в демо сохранены исходные ресурсы и резервные ссылки.

## 2. Добавить CSS

Содержимое [banquets-static.css](banquets-static.css) добавить **в самый конец существующего CSS новогодней страницы**. Он сохраняет ширину карточек, одинаковый размер фотографий и запас вокруг теней. При установке новой полной `styles.css` повторно добавлять его не нужно.

## 3. JavaScript не менять

Скрипт ищет `[data-carousel]` / `[data-dinner-carousel]`. На банкетах этих атрибутов и классов `carousel`/`carousel-track` больше нет — нет автолистания, свайпа, скрытия карточек или фиксированной высоты. Обработчики ссылок и слайдер ужина продолжают работать.

Недостаточно просто спрятать стрелки: старый слайдер продолжит переключать и скрывать карточки. Нужно заменить обёртки в сохранённом HTML и перезагрузить страницу.

Править исходный HTML в CMS, не копировать HTML из DevTools после запуска слайдера. Если такой HTML уже скопирован, у банкетных карточек удалить добавленные скриптом `inert`, `aria-hidden`, `is-active` и inline `height`, `display`, `visibility`, `transform`, `transition`; внешние `carousel-slide`/клоны не переносить. Содержимое и ссылки не удалять.

## 4. Проверка

- После очистки кеша сразу видны все 7 карточек, включая при отключённом JS.
- Порядок: «Дереза Пати» → «Козырный Новый год» → «Высота 2027»; «Тысяча масок и одна ночь» → «Золотое руно»; «Новогодняя ночь - время быть вместе» → «Музыкальный взрыв».
- У банкетов нет стрелок, свайпа или автолистания. Через 5–10 секунд все карточки остаются на месте.
- Слайдер «Вечер больших желаний» сохранён.
- На телефоне фото над текстом; карточки не накладываются и не выходят за колонку.
- Меню, афиши, телефон и заявки нажимаются. Их адреса совпадают с установленными на сайте.

Для полной замены всей страницы используйте [исходники](../) и [INSTALL-FULL-SOURCE.md](../INSTALL-FULL-SOURCE.md).
