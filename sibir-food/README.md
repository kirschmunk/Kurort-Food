# Страница «Питание» санатория «Сибирь»

Интерактивная дизайн-концепция новой страницы питания для сайта санатория «Сибирь».

## Что включено

- адаптивный макет для компьютера, планшета и телефона;
- интерактивные вкладки четырёх форматов питания;
- рабочие слайдеры фотографий;
- форма перехода к подбору путёвки;
- контент из утверждённого текстового документа;
- локальные изображения и шрифты — страница не зависит от внешних библиотек;
- фирменная палитра сайта «Сибирь»: коралловый `#F55361`, тёмно-синий `#2C3550`, почти чёрный `#171717` и светлые нейтральные поверхности.
- прозрачный фон контентных секций: блоки принимают общий фон страницы и не требуют выхода за пределы внешнего контейнера сайта.

## Перед разработкой

Макет предназначен как визуальный и структурный ориентир. При интеграции в действующий сайт разработчику следует подключить существующие компоненты шапки, формы бронирования и подвала, сохранив структуру и визуальную логику контентных блоков.

Контент обёрнут в `.sibir-food-page`. Этот класс задаёт нейтральное встраивание без собственного фонового полотна. У первого блока уменьшен верхний отступ, у блока «Забота в каждой детали» — нижний отступ перед финальным призывом.
